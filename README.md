# 万朝战域（wanchaozhanyu）

三国背景的 **RTS + SLG** 游戏 Demo。基于 Godot 4.7.1，面向移动端横屏（设计基准 1920×1080）。

## 项目简介

本项目为「万朝战域」第一版 Demo，包含完整的地图系统、UI 框架与 HUD，以及经营/战争双阶段的相机与交互。当前版本聚焦地图生成、城市与道路布局、双阶段视角、点击选择与行动菜单等核心功能的可运行演示。

整体完成度约 **92–95%**，23 项自动化测试中 21 项通过，Godot 4.7.1 无报错启动，地图可稳定生成并渲染。

## 功能特性（第一版 Demo）

### 地图系统

- **基础参数**：400×400 格 Grid-based 3D 地图，单格 2.0 世界单位，10×10 Chunk，XZ 平面展开
- **全局连续高度场**：401×401 顶点高度样本，所有 Chunk 共享同一份高度数据，边界无缝
- **四大区域布局**：森林 / 山地 / 湿地 / 中央，四座战略城市分据各方，中央中立主城居中
- **河流系统**：湿地中心 1 条主河道 + 4 条支流，跨 Chunk 连续，河床低于两岸，独立水面 Mesh
- **三条战略主干道**：森林/山地/湿地主城 → 中央主城，A* 寻路 + 走廊高度平滑
- **地形材质分层**：5 种区域材质（草地/森林/山地/湿地/中央）+ 高程明暗

### 地图加载与性能

- **Chunk 流式加载**：三级 LOD（LOD0 完整 / LOD1 精简 / LOD2 远景代理），每帧最多加载 3 个 Chunk
- **Chunk 缓存与回收**：最多 36 个缓存 Chunk，超量自动释放，快速拖动无黑块
- **MultiMesh 批量渲染**：森林树木每 Chunk 数百棵合并为单 Draw Call
- **分帧重建**：迷雾分帧重建，无主线程长卡顿

### 双阶段相机系统

- **经营阶段**：透视 Camera3D，支持平移、缩放（2.0–18.0）、围绕地图中心旋转、60°±35° 俯仰，有世界边界约束
- **战争阶段**：正交投影（size=10.2），固定视角，锁定旋转与俯仰，保留平移与缩放（ortho size 6.6–15.0）
- **共用逻辑地图**：切换时不生成第二张地图，取消活动手势，环境（距离雾）自动适配

### 交互与选择系统

- **点击选择**：屏幕坐标 → SubViewport 坐标 → Camera3D 射线 → 世界坐标 → 格子坐标，与真实高低地形求交
- **选择优先级**：城市 > 资源点 > 空地 Tile
- **中立数据快照**：选择后返回 `get_city_snapshot` / `get_tile_snapshot` / `get_resource_snapshot`
- **移动端输入**：单指拖动、双指缩放、经营模式双指旋转、单击选择（12px 防误触阈值）、长按侦察（0.45 秒）
- **HUD 接入**：`MapArea` 通过 SubViewport 动态加载 `map_world.tscn`，加载失败保留占位层优雅降级，`MapUILayer` 仅按钮拦截点击

### 行动菜单系统（本版新增）

- 点击地图目标（城市/资源点/铁矿/道路/桥梁/隐藏小径/高地）后生成**上下文相关的可选行动**
- 行动按类别着色（红=战斗，绿=资源，蓝=战略），根据当前阵营与目标关系动态生成
- 「攻打」「占领」需二次确认，确认期间切换阵营自动取消非法请求
- `session_id` 机制防止异步结果污染新目标
- 稳定节点架构：面板/标题/详情/结果标签只创建一次，解决 `previously freed` 错误
- 调试面板阵营选择（森林/山地/湿地），切换后行动列表即时刷新

### 超出第一版已实现（可通过开关禁用）

- **LOD 三级系统**（V3）：完整实现，`lod_enabled` 开关控制
- **战争迷雾**（V3）：`FogData` + Chunk 覆盖层 + 每帧可见性更新 + 开局揭示 + 探索统计，`fog_enabled` 开关控制
- **普通道路 / 环路 / 隐藏路径**（V2）：`RoadType.NORMAL` / `RING` / `HIDDEN`
- **桥梁与浅滩**（V2）：桥面 Mesh + 浅滩 Mesh + 桥面 Shader，跨越河流道路自动标记
- **V3 调试面板**：迷雾控制 / LOD 开关 / 预加载开关 / 视野半径 / 阵营选择 / 点击信息展示

## 项目结构

```
万朝战域ui设计/
├── project.godot              # Godot 项目配置
├── main/                      # 主场景
├── map/                       # 地图模块
│   ├── controllers/           # 相机、输入、地图控制器
│   ├── data/                  # 地图数据、配置、行动系统
│   ├── terrain/               # 地形、高度场、Mesh 构建
│   ├── chunks/                # Chunk 流式加载
│   ├── entities/              # 城市实体
│   ├── shaders/               # 水面、桥面 Shader
│   └── debug/                 # V3 调试面板
├── ui/                        # UI 模块
│   ├── screens/               # 页面
│   ├── components/            # 组件（地图区域、资源栏、任务栏、行动面板等）
│   ├── hud/                   # 主界面 HUD
│   ├── scripts/               # 导航管理、UI 构建器
│   └── themes/                # 主题资源
├── addons/                    # 插件（godot_mcp、godot_ai）
└── tests/                     # 无头测试
```

## 运行方式

1. 使用 **Godot 4.7.1** 打开 `万朝战域ui设计/project.godot`
2. 运行主场景即可启动 Demo

> 首次打开需等待 Godot 完成项目导入，再运行以避免类缓存未生成导致的误报。
